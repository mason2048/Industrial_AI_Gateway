# 配置大模型与本地模型

适用于 1.3.0 及以上。在左侧 **模型设置** 配置，再到 **按需数据查询** 提问。默认是离线的“本地规则统计”。EXE 包含接入功能，不包含 Ollama、LM Studio 或模型权重。

## Ollama：本机部署

1. 在 Windows 安装 [Ollama](https://ollama.com/download/windows)，启动它。
2. 在终端下载文本聊天模型：执行 `ollama pull qwen3:8b`，再用 `ollama list` 查看完整模型名称。
3. 软件 **模型设置** 中填写管理口令，服务类型选择 **Ollama**，基础地址填写 `http://127.0.0.1:11434`，模型名称填写 `qwen3:8b`。
4. 本机 Ollama 通常不需要 API Key。点击 **测试模型连接**；测试只发送固定测试问题，候选配置尚未保存，不发送 PLC 数据。
5. 点击 **保存模型设置**。回到 **按需数据查询**，选择设备/变量并提问，例如“当前模拟真空压力是多少？”或“最近一周模拟真空压力有哪些明显变化？”。

首次加载较慢时，将超时从 60 秒调到 120–300 秒。Ollama 请求为非流式聊天，设置 keep_alive=0，请求完成后要求卸载模型；再次提问会重新加载。Qwen3 系列请求关闭思考，优先返回文本。网关平时不请求推理，也不定期分析；Ollama 服务本身可以继续运行。[Ollama 聊天接口](https://docs.ollama.com/api/chat)

使用已下载到本机的权重才是本地推理。Ollama 云模型、远程地址或本机服务转发到云端，仍可能外发数据。页面“本机/局域网”只是服务地址类别，不验证服务内部处理位置。请选择普通本地标签，避免云模型标签。

## LM Studio 和其他兼容服务

在 [LM Studio](https://lmstudio.ai/) 下载并加载文本聊天模型，开启本地服务。选择 **OpenAI兼容接口**，基础地址一般为 http://127.0.0.1:1234/v1，模型名称使用服务中实际标识；未开启鉴权时 Key 留空。模型加载/卸载由 LM Studio 管理，网关不控制其驻留。[官方接口说明](https://lmstudio.ai/docs/developer/openai-compat)

vLLM、llama.cpp 等服务若提供兼容的 /chat/completions 文本接口，也可填写实际基础地址与模型标识，兼容性通过测试确认。云服务填写供应商的 HTTPS 基础 URL、模型名和 Key。不要把 /chat/completions 或 /api/chat 填入基础地址。选择远程服务后，每次提问会发送有限证据与问题。换地址时不会沿用旧服务的 Key。

本版不支持 embedding、图像生成、语音或任意工具执行。

## 可以选择的本地模型

资源为常见量化权重加短上下文的起步估算，受量化方式、上下文、其他程序和运行器影响，不是目标电脑性能保证。

| Ollama 模型名 | 下载体积 | 起步建议 | 用途 |
| --- | --- | --- | --- |
| qwen3:4b | 约 2.5 GB | 16 GB 内存；无独显也可先试 | 资源有限时体验中文解释 |
| qwen3:8b | 约 5.2 GB | 16–32 GB 内存；8 GB 显存更适合加速 | 优先试用的常规中文数据助手 |
| qwen3:14b | 约 9.3 GB | 32 GB 内存；12–16 GB 显存更合适 | 资源充足时做较复杂解释 |
| deepseek-r1:8b | 约 5.2 GB | 16–32 GB 内存；增加超时和输出上限 | 小型推理模型，响应可能更慢 |

模型名与体积来源：[Qwen3 模型库](https://ollama.com/library/qwen3)、[DeepSeek-R1 模型库](https://ollama.com/library/deepseek-r1)。DeepSeek-R1 8B 是小型蒸馏模型，不是完整 671B。设备故障诊断准确率仍需现场样本评价。

## 查询与凭据

- 默认规则模式不访问模型服务。打开页面、配置、采集、定时历史保存不触发推理；只有点击测试或提交问题才触发。
- 测试与推理需本机口令；修改配置和模型查询需版本校验，目标被其他页面修改时重新加载核对。
- 每次只发有限证据：当前最多 50 点；历史按阈值筛选，最多 200 条、扫描最多 10000 条；总上下文最多 40000 字符。指定设备/变量可减少截断。
- 证据包含来源、连接、定义版本、质量、时间和 AI 描述；筛选后的已存样本不代表连续测量，不能据此计算全时段准确均值。截断、未保存、异常质量和缺失均附提示。
- 模型只有文本解释能力，没有 PLC 写入、运行命令或文件操作工具。回答中的操作建议不会执行。
- 模型失败、忙碌、超时明确报错，不用规则结果冒充模型答案。每次独立查询，不保存聊天记录。
- 设置在数据目录 config/ai.json，Key 单独存在 data/ai-secrets/。页面不回显 Key，仅显示是否配置；留空仅在同一服务目标下保留旧 Key，可勾选清除。Key 在本地文件保存，未加密，需保护数据目录。
- 候选测试的 Key 仅留在当前页面内存，便于直接保存；保存成功或离开模型页会清空输入。
- 自动数据库备份不含模型设置及 Key；整目录升级备份包含它们，应按敏感数据保存。换机单独重新配置。公开发行包不带现场模型配置或凭据。

## 排查

| 提示 | 检查方式 |
| --- | --- |
| 无法连接 | 确认模型服务启动、端口和基础地址正确 |
| 模型/接口不存在 | 查看实际模型名；兼容服务地址通常需 /v1 |
| 认证拒绝 | 检查 Key，更换服务地址后重新填写 |
| 超时 | 确认下载完成、减少范围、延长超时或选小模型 |
| 没有最终文本 | 使用文本聊天模型；推理模型可增加输出上限 |
| 配置冲突 | 草稿保留；载入最新配置，核对去向后再修改 |
| 没有历史 | 先启用保存并等待采样；检查日期、变量、来源、连接 |

自动验证覆盖协议、权限、数据范围和错误处理；真实模型质量、电脑速度、显存/内存占用与实体 PLC 业务判断须另行验证。
