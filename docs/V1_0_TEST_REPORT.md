## 浏览器与启动验收

- 使用start.bat启动，本机http://localhost:8080/api/health返回running。
- Vue页面实际渲染，设备总览显示模拟在线、6/6点位和历史压力曲线。
- 点位编辑表单显示完整字段，提交后显示“点位已保存”。
- 实时表格显示6点数据，BOOL/WORD/DWORD/FLOAT正常显示。
- 历史页查询显示24小时压力记录、折线和明细。
- AI页面提交“分析今天真空变化”，显示当天统计、simulation来源、起止时间和证据数量。
- 浏览器检查期间无JavaScript error日志；`node --check frontend/app.js`通过。
- 停止和重新启动脚本进行单独验收；保留现有点表和历史数据。

## 验证边界

- 30分钟补存和7天删除使用时间推进测试，未实际等待7天。
- 没有实体PLC，未验证具体厂商NodeId、账号、证书策略或生产网络断线行为。
- 1000点测试覆盖一次完整协议扫描和正常模拟运行，不是长时间生产稳定性试验。
- AI为本地规则统计，未接入大语言模型、真空专业知识库、健康评分或故障诊断模型。
- V1为受信任本机单用户、单PLC程序，多PLC/MQTT/模型/维修Agent仅预留模块边界。
