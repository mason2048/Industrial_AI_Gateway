# 基础功能交付与后续路线

1.2.0 新增 Windows 自带运行环境的 EXE、便携 ZIP、持久化数据目录、重复双击与端口回退、界面退出，以及 GitHub Windows 实际 EXE 构建/浏览器验收/发行流程。

1.2.1 修复删除点位后新增/复制重新使用已删除 ID 导致的身份冲突。新建 ID 由后台依据当前及已删除点位记录自动选择，页面 ID 只读；列表使用连续序号，固定点位 ID 单独显示并继续关联 Excel 和历史。升级保留原 `gateway-data`，无需重新编号或删除历史。

目标：Windows 单 PLC、本机只读现场试点；Mac 开发；允许明确标记的历史缺口。

1.3.0 新增独立模型设置：Ollama 和 OpenAI兼容服务、候选测试、模型名/超时/输出/温度/Key配置。默认规则；用户提问时调用，有限只读证据，无控制工具。查询绑定配置版本及口令，Key独立保存。修复空点表与重启恢复、PLC账号/证书清除入口及AI历史并发扫描完整性误报。模型运行软件/权重另行安装，实际质量与目标电脑性能待验证。

1.3.1（2026-10-09）将本地历史保存与提问时AI取数分开。点位可选择变化阈值筛选或时间间隔取样，间隔可独立设置或继承保存间隔。当前偏好应用于已有历史，保留基准、质量变化和原定义阈值，不补造样本；关闭保存只停止新增记录，已有历史仍可查。列表与Excel保留策略，旧模板默认变化，AI仍仅在提问时调用。

2026-10-02基础功能增强已交付：连接页配置采集周期/批量点数/默认历史周期/保留天数；点位独立间隔/变化记录开关/小数位数；Excel空模板与旧模板兼容；不保存历史的点位实时问答；AI历史阈值筛选；Windows安装/预检/服务/离线依赖/干净发行包入口。读取方式为批量轮询，AI支持按需只读规则查询或可配置模型。订阅、自动心跳握手和真实写入仍在后续范围。

接口兼容：旧历史明细结构保留；新增series/variables/ready/diagnostics/预检接口。修改操作现在必须带管理口令和If-Match。Tag.revision由数据库托管，历史新增connection_id/tag_revision与可空源时间。旧库身份标记legacy，不推测设备来源。

代码验证与现场验收分开。Windows服务的实际注册/开机运行、具体实体PLC的证书策略/HMI读值、断网恢复和72小时连续运行仍须目标环境验证，不能由本机模拟测试代替。详见TEST_REPORT.md。

后续独立范围：

- 采集增强：节点浏览、更多PLC数据类型、比例/偏移、设备模板。
- 智能分析：规则报警、运行状态识别、趋势特征、知识库和有证据的模型解释。
- 多设备：局域网身份与角色、HTTPS、多PLC；依据容量测试决定数据库迁移。
- 控制版本：写入允许列表、工艺限制、回读确认、未知结果处理和控制审计，单独验证。
