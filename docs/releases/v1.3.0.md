新增可配置的大模型问答：在“模型设置”选择 Ollama 或 OpenAI兼容接口，填写服务地址、模型名称、API Key、超时和输出长度，测试后保存，再到“按需数据查询”提问。

- 支持本地 Ollama、LM Studio 及兼容聊天服务。默认仍是离线本地规则。
- 只有用户测试或提问时调用模型；发送有限的当前/阈值历史证据，附来源、质量和时间。没有 PLC 写入或命令执行工具。
- Ollama 请求结束后请求卸载模型，Qwen3 请求关闭思考；其他运行器自行管理驻留。EXE 不含模型软件或权重。
- 口令与配置版本保护调用；Key 不回显，换地址不沿用旧 Key，私密文件不进入自动数据库备份或发行包。
- 修复最后一个点位不能删除、清空后重启恢复旧 Excel。支持0–1000点，旧历史和固定ID保留。
- PLC连接页新增清除已有用户名/证书选项，便于切换匿名访问。
- AI变化历史扫描固定记录边界，避免延迟落库造成重复/漏读却误报完整；并发清理时提示不完整。

Windows64位用户下载ZIP、完整解压后双击 IndustrialAIGateway.exe，无需安装Python或数据库。[模型安装与推荐](https://github.com/mason2048/Industrial_AI_Gateway/blob/main/docs/MODEL_SETUP.md)。

升级：正常退出并备份完整 gateway-data，再替换原EXE，保留数据目录。无需删库或重导点表。模型Key属于敏感文件，不要公开上传。

发行前执行Python、前端和真实浏览器回归，以及Windows实际EXE启动与同一浏览器验收。模型协议验证使用临时模拟服务，没有下载或运行真实模型权重；模型质量、目标电脑性能和实体PLC连续运行仍须现场验证。
