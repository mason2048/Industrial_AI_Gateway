修复删除点位后再次新增的冲突：删除 ID 8、9 后，旧版可能再次申请已删除 ID，导致新增失败。

- 新增和复制点位自动选取未使用过的点位 ID，用户无需手填。
- 点位列表首列改为连续序号，删除后仍按 1、2、3……排列。固定点位 ID 在变量下方显示，继续关联 Excel 和历史。
- 获取新 ID 失败时保留草稿，可重新获取；并发修改仍需重新加载确认，避免覆盖他人的修改。
- 已有点位和历史保持原关联，不需要重新编号或删除数据。

Windows 64 位用户下载 ZIP、完整解压后双击 IndustrialAIGateway.exe，无需安装 Python 或数据库。首次启动是 6 个模拟点位，真实 PLC 仍通过 OPC UA 只读接入；外部大模型尚未接入。

升级：先使用“退出软件”或“停止软件.cmd”正常停止，备份完整 gateway-data，再替换同目录 EXE，并保留原 gateway-data。无需重新导入点表。
